# llm-from-scratch

Working through the [LLM From Scratch](https://github.com/angelos-p/llm-from-scratch)
workshop — a six-part hands-on course that builds a tiny GPT
(character-level tokenizer, Shakespeare dataset ~1 M chars, vocab 65)
from scratch in PyTorch.
